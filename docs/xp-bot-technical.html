业务 Agent / PRODUCT & ENGINEERING

XP BOT

面向企业业务人员与商家用户的双端 AI Agent 工作空间。

需求说明 · 功能架构 · 技术依据更新于 2026.11.13

01

要解决的问题

面向企业业务人员与商家用户，把散落的资料、经营数据、任务与可复用技能放进同一个 Agent 工作空间。独立负责需求、产品设计、开发、Windows 与 macOS 双端交付及部署。

03

需求与功能范围

模块用户需求交付与边界
定时自动化重复流程可以按计划执行，不必一直盯住界面。已有五类业务流程；执行依赖设备、网络、本人账号权限和有效登录。
私人知识库从自己的资料里检索相关内容，并回查原文。解析 Word、PDF，图片 OCR，视频语音转写。按片段建立向量索引，保留出处，支持多轮追问与 Skill 联动。
图片与模板重复使用参考图、构图和固定创作要求。保存与调用参考图及创作规则；生图需要相应外部服务和权限。
数据与日报按明确日期与范围采集、核验和导出数据。搜索词榜单、经营取数、日报；缺失和失败不能被当作零。
Skill Creator把已验证的工作步骤变成可复用技能。描述、创建、验证、复用；技能保存在本机，避免写入敏感信息。
接入与工具已有模型权限后，减少配置和环境准备。接入路径、Python 工具环境与模型线路配置；公司与个人配置分开管理。

04

五类真实工作流

流程工作内容输出
经营预警监管归集星级、体验分、履约与售后线索，检查异常。监管报告、分类明细和执行记录。
对应表维护全量导出、匹配标识、核验和增量维护。可回查的对应关系与导出文件。

新品申报与打标准备申请资料，保留审批与提交边界。申请文件与待确认事项；自动出稿不代表审批完成。

05

功能架构与数据流

  1. 01用户入口

    自然语言任务、知识库、图片、快链笔记与任务管理。

  2. 02Agent 与技能

    识别目标、调用已有技能、组织工具步骤并反馈状态。

  3. 03工具与工作流

    Python 工具、资料处理、数据采集与既定业务流程。

  4. 04本地资料与结果

    资料索引、任务记录和结果文件；回答按所选模型线路处理。

用户选定资料后，程序解析、分块并建立向量索引。Agent 检索相关片段，结合证据回答并提供原文出处。

06

RAG 测试集与评测

100 条黄金测试集由业务人员问卷和资深业务经理任务各贡献 50%。筛查去重后，纳入 14 条红线用例、20 条边界与长尾用例。

每条样本由问题、参考答案与证据片段组成，覆盖单文档、跨文档、多轮追问和证据不足场景。

指标评测口径
Recall@5检查前五条检索结果对标注证据的覆盖。
引用准确率检查回答引用的出处能否支持结论。
答案正确率核对关键事实和业务口径。

首测后将红线和代表性用例纳入版本回归。每周选取 10–20 条探索用例，按检索遗漏、引用错误与答案偏差归因，复现后补入回归集。
